# face-changer

## Что это

Telegram-бот: пользователь присылает одну фотографию, бот подставляет лицо в
заранее подготовленный видео-шаблон через Higgsfield API (модель Genjutsu,
motion transfer / subject swap) и возвращает готовое видео.

Продукт для рынка РФ. Оператор — самозанятый (НПД), приём платежей — ЮKassa
для самозанятых (в MVP — заглушка).

## Стадия

**MVP.** Один предопределённый шаблон. Оплата проходит автоматически
(заглушка, для собственных проверок). Каталог шаблонов хранится в данных,
но UI выбора ещё нет — активный шаблон выбирается по умолчанию.

## Границы MVP

**Входит:**
- онбординг с согласием на обработку фото;
- приём и валидация одной фотографии;
- постановка задания в очередь и генерация через Higgsfield API;
- polling статуса задачи;
- выдача готового видео в чат;
- учёт заказов, кредитов и событий;
- админ-команды и гейт по остатку кредитов;
- удаление исходного фото после завершения задания.

**Не входит (осознанно отложено):**
- выбор шаблона пользователем (каталог как UI);
- реальная оплата и чеки;
- Telegram WebApp;
- история заказов и личный кабинет;
- пользовательские промпты;
- подписки и рекуррентные платежи;
- S3, CDN, внешняя аналитика, Redis, Celery;
- мультиязычность;
- реферальная программа;
- модерация контента сверх проверки «одно лицо в кадре».

## Соглашения

**Деньги.** Только целые числа: копейки (`*_kopecks`). Никаких float.

**Время.** Всё в UTC, `timestamptz`. Локальное время — только в текстах для
пользователя.

**Статусы.** Только через `domain/order_service.transition()`. Прямая запись
`order.status` из хендлеров запрещена.

**ID.** Внешние идентификаторы (Telegram, платёж, request_id движка) —
отдельные `UNIQUE`-колонки. Внутренние PK — `bigserial`.

**Идемпотентность.** Три уровня: `update_id` (Telegram), `payment_id`
(платёж), `idempotency_key` (задание движка). Повторный вызов не должен
приводить к повторному списанию.

**Приватность.** Фото пользователя не попадает в логи, не хранится дольше
задания и удаляется при любом терминальном статусе. В логах — только
идентификаторы.

**Тексты.** Все строки — в `bot/texts.py`, никакой локализации в хендлерах.

**Шаблоны.** Шаблон = папка `templates/<key>/` с `source.mp4` и
`config.yaml`. Добавление шаблона не требует изменения кода.

**Ошибки наружу.** Пользователь всегда получает либо видео, либо возврат,
либо явный отказ с причиной. Молчаливых сбоев нет.

## Стиль кода

Функциональное ядро, императивная оболочка. Бизнес-логика — **чистые функции по
максимуму**: без I/O, без чтения часов и случайности изнутри, неизменяемые
`dataclass(frozen=True)`, ошибки как значения (`Result`), явные зависимости
параметрами. Агрессивная декомпозиция: одна функция — одно действие.
Подробно, с примерами и лимитами — `AGENTS.md`.
