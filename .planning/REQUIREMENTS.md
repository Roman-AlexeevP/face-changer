# Requirements: Face Changer

## Scope reset — 2026-11-09

Активный план сброшен до двух внешних гейтов. Завершённый mock/stub-срез
сохранён в `.planning/archive/2026-11-09-pre-reset/` и остаётся регрессионной
базой, но его старые REQ-ID больше не являются активным backlog.

Текущая цель — подтвердить, что продукт можно связать с двумя внешними
системами: генерацией Higgsfield и минимально доступной оплатой.

## Goal A: Higgsfield generation probe

- [ ] **HF-01**: В локальном `.env` конфигурируются ключи и модель без попадания
  секретов в git, логи и тестовые артефакты.
- [ ] **HF-02**: Live-probe подтверждает авторизацию и фактический формат
  submit-запроса, включая endpoint, поля input и idempotency-поведение.
- [ ] **HF-03**: Live-probe подтверждает upload или достаточность публичных URL,
  формат `request_id`, `status_url` и имена промежуточных статусов.
- [ ] **HF-04**: Live-probe получает терминальный результат, подтверждает поле
  `video.url`, скачивает mp4 и фиксирует время генерации и фактический расход.
- [ ] **HF-05**: Формы ошибок минимум для auth, bad input, rate limit, no credits,
  provider failure и moderation сопоставлены с типами движка без потери
  диагностического контекста.
- [ ] **HF-06**: Один реальный тестовый заказ проходит через существующий worker
  pipeline до результата; повторный запуск не создаёт дубликат submit, а
  `request_id` позволяет продолжить polling после рестарта.

## Goal B: minimal viable payment

- [ ] **PAY-01**: До реализации выбран минимальный реально доступный для проекта
  платёжный маршрут: провайдер, транспорт, sandbox/production режим и способ
  подтверждения оплаты. Решение обосновано доступностью API и требованиями РФ.
- [ ] **PAY-02**: Реализован `PaymentProvider` для выбранного маршрута: создание
  счёта передаёт сумму в копейках, order ID и идемпотентный ключ, а наружу
  возвращается `payment_id` или платёжная ссылка.
- [ ] **PAY-03**: Подтверждён успешный платёж: заказ однократно переходит в
  `paid`, ledger получает ожидаемые записи, пользователь получает запрос фото.
- [ ] **PAY-04**: Отказ, отмена и повторное уведомление безопасны: повторная
  обработка одного `payment_id` не меняет баланс и не списывает заказ дважды.
- [ ] **PAY-05**: Секреты и webhook/подтверждение платежа защищены; `stub`
  остаётся только явным dev/test-провайдером и не выбирается в live-конфигурации.
- [ ] **PAY-06**: Есть минимальный проверяемый сценарий оплаты в sandbox либо
  production-safe режиме, не требующий ручного изменения записей в БД.

## Integration gates

- [ ] **GATE-01**: Фактический контракт Higgsfield зафиксирован в
  `docs/higgsfield-contract.md`; использованные поля больше не помечены как
  неподтверждённые.
- [ ] **GATE-02**: Фактический контракт оплаты и выбранный транспорт описаны в
  документации; повторяемый тестовый сценарий запускается по инструкции.
- [ ] **GATE-03**: Mock/stub regression suite остаётся зелёным после подключения
  адаптеров; live-секреты не требуются для обычного CI/test запуска.
- [ ] **GATE-04**: По каждому гейту принято решение `go` или `stop` с измеренными
  данными: доступность, стоимость, задержка, ошибки и следующий шаг.

## Repository agent workflow

Эти требования поддерживают демонстрацию и воспроизводимость агентной работы;
они не являются отдельной продуктовой фазой и не требуют внешних credentials.

- [ ] **REPO-01**: GitHub Actions на push и pull request запускает ruff и полный
  Docker-тестовый прогон с PostgreSQL.
- [ ] **REPO-02**: `docs/agent-workflow.md` описывает для нового агента порядок
  чтения контекста, планирования, реализации, проверки и обновления состояния.
- [ ] **REPO-03**: `tasks.cmd demo` запускает mock E2E-сценарий без Telegram,
  Higgsfield, платёжных ключей и ручного SQL.

## Out of scope until both gates pass

- нормализация и сложная доставка видео;
- каталог шаблонов и UX-долг «Ещё раз»;
- админка, дневные лимиты и расширенная эксплуатация;
- S3/CDN, Redis, Celery и горизонтальное масштабирование;
- полноценная фискализация, если выбранный минимальный платёжный маршрут не
  требует её на этапе проверки гипотезы.
