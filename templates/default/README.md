# Шаблон `default`

Сюда кладутся файлы шаблона, которые попадают в образ при сборке:

- `source.mp4` — видео-шаблон, в который подставляется лицо. Именно этот путь
  записывается в `templates.source_path` при сиде (`templates/default/source.mp4`).
- `prompt.txt` — текстовый промпт для движка. Если файла нет или он пустой,
  используется промпт по умолчанию из `app/db/seed.py`.

Порядок:

1. Положите `source.mp4` и `prompt.txt` в этот каталог.
2. Пересоберите образ (`tasks.cmd up` собирает его заново).
3. На чистой базе шаблон засеется автоматически при старте бота.

Без `source.mp4` движок не сможет отправить видео-шаблон и заказ завершится
ошибкой `template_missing`/`engine_failed`.
