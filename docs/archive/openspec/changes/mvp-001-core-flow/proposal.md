# Change: mvp-001-core-flow

## Why

Нужно проверить ключевую гипотезу продукта: пользователь готов заплатить за
видео со своим лицом в готовом шаблоне, и качество генерации Higgsfield
(Genjutsu) достаточно для продажи.

Сейчас нет ни кода, ни проверенного пайплайна. Пока не доказано качество и
воронка, любая работа над оплатой, каталогом и WebApp — преждевременна.

## What Changes

- Вводится Telegram-бот с путём `/start` → согласие → оплата (заглушка) →
  фото → генерация → видео.
- Вводится очередь заданий в PostgreSQL (`SKIP LOCKED`) и отдельный процесс
  воркера.
- Вводится сменный `VideoEngine` с реализациями `mock` и `higgsfield`.
- Вводится сменный `PaymentProvider` с реализацией `stub` (реальная оплата —
  отдельным изменением).
- Вводится каталог шаблонов как данные: один предопределённый шаблон,
  помеченный `is_default`.
- Вводятся правила приватности: фото удаляется при терминальном статусе.

## Capabilities

Затрагиваются (создаются) все спецификации MVP:

- `tg-entry` — вход, согласие, приём фото
- `template-catalog` — шаблон как данные, шаблон по умолчанию
- `generation` — submit, polling, ретраи, таймауты, ошибки
- `billing` — заказ, заглушка оплаты, ledger, возвраты
- `delivery` — выдача видео, нормализация, идемпотентность
- `privacy-retention` — удаление фото, логи без PII
- `ops` — админ-команды, гейты, алерты

## Impact

**Код:** создаётся с нуля (`app/`, `templates/`, `docker-compose.yml`).

**Данные:** 6 таблиц (`users`, `templates`, `orders`, `jobs`, `ledger`,
`events`), миграции с нуля.

**Внешние системы:** Telegram Bot API, Higgsfield API. Обе — за интерфейсами,
подмена не требует изменения домена.

**Риски:**
1. Качество Genjutsu на конкретном шаблоне может не подойти — проверяется
   первым этапом, до написания бота.
2. API Higgsfield может быть недоступен для РФ — проверяется одновременно.
3. Стоимость кредитов неизвестна — уточняется на первом тестовом прогоне.

## Out of Scope

Реальная оплата и чеки, выбор шаблона пользователем, WebApp, история заказов,
пользовательские промпты, подписки, S3, Redis, внешняя аналитика,
мультиязычность.
